🔄 Data Flow: Research Query

1. User Query → Streamlit UI receives research question
↓
2. Orchestrator → Initializes ResearchState and starts workflow
↓
3. Validate Query Agent → Fast path keyword check OR LLM validation (Llama-3.2-3B)
↓
4. Retriever Agent → Parallel search: Local KB (1.5s) + PubMed (2.5s) → Top-3 each
↓
5. Critical Analysis Agent → Synthesize evidence using Llama-3.1-70B
↓
6. Report Builder Agent → Generate Markdown report using Llama-3.1-70B
↓
7. Results Display → Show report + retrieved documents + matching sections
